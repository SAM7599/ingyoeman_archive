# 잉여맨 추억자료실

네이버 카페 「잉여맨추억자료실」 영상을 쉽게 찾아보는 팬 자료실입니다.
사이트 주소: https://sam7599.github.io/ingyoeman_archive/

## 파일 설명
- `videos.json` : 영상 목록 (제목 `title`, 분류 `category`, 카페 글 주소 `url`, 선택: 썸네일 `thumb`, 길이 `duration`, 유튜브 주소 `youtube`)
- `notice.json` : 맨 위 공지
- `config.js` : 분류 이름과 순서
- `index.html`, `style.css`, `app.js` : 화면과 동작
- `vendor/qrcode.js` : QR코드 만드는 도구 (QR Code Generator for JavaScript, © 2009 Kazuhiko Arase, MIT License)
