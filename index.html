영상을 누르면 네이버 카페 게시글로 이동해요

HOW TO USE

이용방법

처음 오셨어도 어렵지 않아요. 아래 순서대로 보시면 돼요.

1

영상 보기

보고 싶은 영상 카드를 누르면 네이버 카페 게시글이 열려요. 컴퓨터에서는 새 탭으로 열리고, 휴대폰에서는 네이버 카페 앱이 설치돼 있으면 앱으로 열려요. 영상은 이 사이트가 아니라 카페에 있어서, 카페 가입이나 네이버 로그인이 필요할 수 있어요.

2

영상 찾기

  • 검색: 위쪽 검색창에 제목 일부를 입력하세요.
  • 분류: 목록 위 동그란 버튼(예능, 음악 등)을 누르면 그 분류만 보여요.
  • 정렬: 오른쪽 메뉴에서 최신순, 오래된순, 제목순을 고를 수 있어요.
3

즐겨찾기 ♡

카드 오른쪽 위 하트를 누르면 즐겨찾기에 담겨요. 위쪽 즐겨찾기 버튼을 누르면 담은 영상만 모아 볼 수 있어요. 다시 누르면 전체 목록으로 돌아와요.

  • 즐겨찾기는 지금 쓰는 기기와 브라우저에만 저장돼요. 휴대폰과 컴퓨터는 따로 관리돼요.
  • 브라우저의 인터넷 사용 기록을 지우면 함께 사라질 수 있어요.
4

썸네일 제보 📷

영상 썸네일이 없거나 마음에 안 들면 알려주세요. 카드의 카메라 아이콘을 누르면 GitHub 글쓰기 창이 열리고, 영상 정보가 미리 채워져 있어요. 아래 칸에 이미지를 끌어다 놓거나 주소를 붙여넣고 올리면 끝이에요.

  • 컴퓨터에서는 카드에 마우스를 올리면 카메라 아이콘이 나타나요.
  • 제보하려면 GitHub 로그인이 필요해요. 확인 후 사이트에 반영돼요.
5

화면 모드 바꾸기 ☾ / ☀

오른쪽 위 둥근 버튼을 누르면 밝은 화면과 어두운 화면이 바뀌어요. 고른 모드는 기억해 둬요.

자주 묻는 질문

영상이 안 열려요

카페에 가입하지 않았거나 로그인이 안 된 경우가 많아요. 네이버 로그인 후 카페 가입 여부를 확인해 주세요. 카페 글이 삭제됐을 수도 있어요.

영상이 이 사이트에 직접 들어 있나요?

아니요. 이 사이트는 카페 영상을 쉽게 찾도록 모아 둔 목록이에요. 실제 영상은 모두 네이버 카페에 있어요.

새 영상은 언제 올라오나요?

카페에 새 영상이 올라오면 목록에도 추가돼요. 바로 반영되지 않을 수 있어요.

즐겨찾기가 사라졌어요

브라우저 기록을 지웠거나 다른 기기에서 접속했을 수 있어요. 즐겨찾기는 각 기기에 따로 저장돼요.

시청은 카페 가입/로그인이 필요할 수 있어요
♡ 즐겨찾기는 이 브라우저에만 저장돼요 · 비공식 팬 목록 사이트
