이용방법

처음 오셨어도 어렵지 않아요. 순서대로 보시면 돼요.

  1. 영상 보기

    보고 싶은 영상을 누르면 네이버 카페 글이 열려요. 컴퓨터에서는 새 탭으로, 휴대폰에서는 네이버 카페 앱으로 열려요. 영상은 카페에 있어서 카페 가입이나 네이버 로그인이 필요할 수 있어요.

  2. 영상 찾기

    검색: 맨 위 검색창에 제목 일부를 적어요.
    분류: 탈출맵, 상황극 같은 분류를 누르면 그것만 보여요.
    연도와 정렬: 목록 위에서 연도를 고르거나 최신순, 오래된순, 제목순으로 바꿔요.
    보기 방식: 큰 그림으로 보거나, 게시판처럼 한 줄씩 볼 수 있어요.

  3. 즐겨찾기

    영상의 하트(♡)를 누르면 담겨요. 위쪽 즐겨찾기 메뉴에서 모아 볼 수 있어요. 지금 쓰는 기기와 브라우저에만 저장되고, 인터넷 사용 기록을 지우면 함께 사라질 수 있어요.

  4. 최근 본 영상

    눌러 본 영상은 최근 본 영상 메뉴에 차례로 쌓여요. 보다 만 영상을 다시 찾을 때 편해요.

  5. 아무거나 보기

    뭘 볼지 모르겠으면 아무거나 보기를 눌러 보세요. 영상 하나를 골라 드려요.

  6. 썸네일 제보

    영상의 카메라 버튼을 누르면 GitHub 글쓰기 창이 열리고 영상 정보가 미리 채워져요. 이미지를 끌어다 놓고 올리면 돼요. GitHub 로그인이 필요하고, 확인 후 반영돼요.

자주 묻는 질문

영상이 안 열려요

카페에 가입하지 않았거나 로그인이 안 된 경우가 많아요. 네이버에 로그인한 뒤 카페 가입 여부를 확인해 주세요. 카페 글이 지워졌을 수도 있어요.

영상이 이 사이트에 직접 들어 있나요?

아니요. 여기는 카페 영상을 쉽게 찾도록 모아 둔 목록이에요. 영상은 네이버 카페에 있어요.

즐겨찾기가 사라졌어요

브라우저 기록을 지웠거나 다른 기기로 접속하면 보이지 않아요. 기기마다 따로 저장돼요.

새 영상은 언제 올라오나요?

운영자가 확인하는 대로 목록에 추가해요. 카페보다 조금 늦을 수 있어요.
